# 哈夫曼树可视化演示

> 交互式展示哈夫曼树（Huffman Tree）的构建过程与非定长字符编码方案生成。

在线演示：[https://bing-fei.github.io/huffman_tree_visualize/](https://bing-fei.github.io/huffman_tree_visualize/)

---

## 项目简介

本项目是一个纯前端交互式网页，用于可视化展示**哈夫曼编码**的完整构建过程。用户可以输入自定义字符集及频率，观察哈夫曼树如何通过贪心策略逐步合并最小频率节点，最终生成最优前缀编码方案。

核心特色：
- **逐步动画演示**：可控制播放速度，支持单步前进/后退
- **实时可视化**：使用 SVG 绘制树结构，动态展示每一步的合并操作
- **灵活输入**：支持加载预设示例、随机生成字符集、手动编辑
- **编码结果分析**：展示最终编码表、压缩率等统计信息

## 模块说明与依赖关系

### 模块依赖图

```
index.html
  ├── css/style.css          (无依赖)
  ├── js/huffman.js          (无依赖，纯算法模块)
  ├── js/visualizer.js       (依赖 huffman.js 的 HuffmanNode 类型)
  └── js/app.js              (依赖 huffman.js + visualizer.js)
```

各模块通过全局变量通信，无需打包工具，可直接在浏览器中运行。

### 1. `js/huffman.js` — 哈夫曼算法核心

**职责**：实现哈夫曼编码的完整算法逻辑。

| 组件 | 说明 |
|------|------|
| `HuffmanNode` | 哈夫曼树节点类，包含字符、频率、左右子节点、唯一 ID |
| `MinHeap` | 最小堆（优先队列），按频率升序排列 |
| `buildHuffmanTree()` | 构建哈夫曼树，每一步记录森林状态、高亮节点、操作描述 |
| `generateCodes()` | 从根节点递归遍历，生成各字符的哈夫曼编码 |
| `calculateStats()` | 计算定长编码/哈夫曼编码的位数、压缩率、平均码长等统计信息 |

**设计要点**：
- `buildHuffmanTree` 返回 `steps` 数组，每步记录当前的**森林**（堆中所有根节点）、**被合并的两个节点 ID**（用于高亮）和**新创建的节点 ID**
- 步骤类型分为 `init`（初始化）、`merge`（合并）和 `complete`（完成）三种

### 2. `js/visualizer.js` — SVG 可视化引擎

**职责**：将哈夫曼树的构建过程渲染为 SVG 图形。

| 组件 | 说明 |
|------|------|
| `TreeVisualizer` | 可视化主类，管理 SVG 画布、定义渐变/滤镜 |
| `_layoutForest()` | 森林布局算法，将多棵树水平排列 |
| `_layoutTree()` | 单树布局算法，叶子节点从左到右等距排列，父节点居中于子节点之上 |
| `_drawEdge()` | 绘制边（父→子），附带 "0"/"1" 编码标签 |
| `_drawNode()` | 绘制节点（叶子=圆角矩形，内部=圆形），支持高亮/新建状态 |

**设计要点**：
- 使用 SVG `<defs>` 定义渐变填充和发光滤镜，提升视觉品质
- 每次渲染步骤时，根据森林中所有树计算布局，动态调整 `viewBox` 实现自适应
- 新建节点使用红色渐变 + 发光动画，被合并节点使用橙色高亮 + 脉冲动画

### 3. `js/app.js` — 应用逻辑

**职责**：管理用户交互、状态流转和 UI 更新。

| 功能 | 说明 |
|------|------|
| 输入管理 | 添加/删除/编辑字符和频率，加载示例，随机生成 |
| 构建触发 | 读取表格数据 → 调用 `buildHuffmanTree` → 渲染第一步 |
| 播放控制 | 播放/暂停、上一步/下一步、速度调节（1x-10x）、重置 |
| 结果展示 | 编码结果表格、统计卡片（定长位数、哈夫曼位数、压缩率、平均码长） |
| Toast 提示 | 替代 `alert()`，提供友好的消息提示 |

**状态管理**：
- `AppState` 对象集中管理所有应用状态（字符列表、步骤、当前索引、播放状态等）
- `DOM` 对象缓存所有 DOM 引用，避免重复查询

### 4. `css/style.css` — 样式表

**设计原则**：
- 使用 CSS 自定义属性（`--color-*`, `--sp-*`, `--radius-*`）统一管理主题
- 卡片式布局，侧栏固定宽度 + 主区域自适应
- 响应式设计：900px 以下切换为单列布局，480px 以下进一步适配
- SVG 节点动画：`@keyframes nodeAppear`（新节点出现）、`@keyframes nodePulse`（高亮脉冲）

## 哈夫曼算法原理

### 算法步骤

1. **初始化**：将每个字符视为一棵只有根节点的树，放入最小堆（按频率排序）
2. **贪心合并**：反复从堆中取出两棵频率最小的树，合并为一棵新树（频率=两子树之和），放回堆中
3. **完成**：当堆中只剩一棵树时，即为哈夫曼树

### 编码生成

- 从根节点到任意叶子节点的路径，左转记为 `0`，右转记为 `1`
- 路径上的 0/1 序列即为该字符的哈夫曼编码
- 哈夫曼编码是**前缀编码**（任何字符的编码都不是另一个字符编码的前缀），可实现无损压缩

### 最优性

哈夫曼编码是贪心算法的经典应用，对于给定的字符频率分布，它能生成**平均编码长度最短**的前缀编码方案，等价于最小化加权路径长度（WPL）。

## 使用方法

### 本地运行

1. 克隆仓库：
   ```bash
   git clone https://github.com/bing-fei/huffman_tree_visualize.git
   cd huffman_tree_visualize
   ```

2. 直接在浏览器中打开 `index.html`，或使用本地服务器：
   ```bash
   # Python
   python -m http.server 8080
   
   # Node.js
   npx serve .
   ```

3. 访问 `http://localhost:8080`

### GitHub Pages 部署

1. 将代码推送到 GitHub 仓库
2. 进入仓库 Settings → Pages
3. Source 选择 `main` 分支，目录选择 `/ (root)`
4. 保存后等待部署完成
